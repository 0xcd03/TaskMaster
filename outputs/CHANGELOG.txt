TaskMaster v0.2.0

- Tables now paint their full client width without a trailing white strip; the result area uses the active application theme.
- Added row context menus for process, service and startup actions.
- Startup entries expose native checked state for enabled/disabled items.
- Memory optimization results use an in-app report panel with a Details action.
- Settings menu items mark the active language, theme, refresh interval and process-tree mode.

- New TaskMaster-inspired shield application icon, embedded at 16–256 px.
- Immediate sidebar navigation and selected-state highlighting; stale snapshots are rejected.
- Correct maximization limits, per-tick ListView state updates and asynchronous shell icons.
- Consistent themed menu/search/header/sidebar/cells.
- Process icons and resource heat coloring; corrected mapping and numeric values.
- Real working-set trim with physical RAM percentage before/after and detailed results.
- Extended isolated tests for 5000 rows, navigation latency, color paths and memory trim.

Network per process remains unavailable. I/O is not physical disk throughput. Working-set trim is not forced memory compression. Binaries remain unsigned.

- Fixed the v0.2.1 startup crash in LVN_GETDISPINFO; added registry-style tree guides and branch glyphs.
