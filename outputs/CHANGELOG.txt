TaskMaster v0.3.1

- CPU values now include % in RU/EN, for individual processes and tree aggregates. Numeric sorting is unchanged; partial aggregates use >= semantics with the compact greater-or-equal glyph.
- Added a native vector rocket/speed-streak animation inside the memory button, following the supplied PC Boost video.
- Starts before background cleanup is queued; a dedicated33ms UI timer continues until worker completion. Shows a check mark or error indicator, then restores the button. Repeated clicks are disabled during cleanup.
- Reports inspected snapshot entries without claiming a freed-memory progress percentage.
- Global trim yields25ms between successes, temporarily uses BELOW_NORMAL worker priority and handles at most32 successful targets per pass. Original thread priority is restored on every exit.
- Added isolated animation lifecycle/offscreen-render and priority restoration tests; all existing UI/model tests remain passing.

The animation is not a claim that system stalls are eliminated. Individual EmptyWorkingSet calls and subsequent page faults remain controlled by Windows. The time budget is checked between calls. Global trim was not run on all user processes during automated tests. Binaries remain unsigned.
